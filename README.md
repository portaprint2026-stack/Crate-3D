# Impulso

Landing page responsive creada con React y Vite. Incluye una vista previa del producto, navegación móvil y un formulario de registro de demostración.

## Requisitos

- Node.js 18 o posterior
- npm

## Empezar

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
npm run preview
```

El formulario muestra una confirmación en el navegador; para registrar usuarios de verdad, conéctalo a un servicio o API.
